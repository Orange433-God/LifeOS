# 第三章 深度学习基础

## 3.1 深度学习概述

深度学习是机器学习的一个子领域，它使用多层神经网络来自动学习数据的层次化特征表示。深度学习的"深"指的是网络包含多个隐藏层，能够学习越来越抽象的特征。

### 3.1.1 为什么深度学习很重要？

- **自动特征提取**：传统 ML 需要手工特征工程，深度学习自动学习特征
- **规模化能力**：随着数据和计算能力的增长，性能持续提升
- **端到端学习**：原始输入直接映射到最终输出

## 3.2 神经网络基础

### 3.2.1 感知机

感知机是最简单的人工神经网络，由 Rosenblatt 在 1957 年提出。它接收多个输入，加权求和后通过激活函数输出。

### 3.2.2 多层感知机（MLP）

多层感知机由三部分组成：
- **输入层**：接收原始特征
- **隐藏层**：一个或多个中间层，进行非线性变换
- **输出层**：产生最终预测

### 3.2.3 激活函数

- **Sigmoid**：将输出压缩到 (0,1) 之间，适合二分类
- **Tanh**：将输出压缩到 (-1,1) 之间
- **ReLU**：max(0,x)，解决了梯度消失问题，是目前最常用的激活函数
- **Softmax**：将输出转换为概率分布，适合多分类

### 3.2.4 损失函数

- **均方误差（MSE）**：回归任务
- **交叉熵损失**：分类任务
- **Hinge Loss**：SVM 使用的损失函数

## 3.3 训练神经网络

### 3.3.1 反向传播

通过链式法则计算损失函数对每个权重的梯度，然后使用梯度下降更新权重。

### 3.3.2 优化算法

- **随机梯度下降（SGD）**：每次使用一个样本更新
- **动量法（Momentum）**：加速 SGD 并减少震荡
- **Adam**：自适应学习率，结合动量和 RMSProp
- **学习率调度**：学习率衰减、余弦退火等

### 3.3.3 正则化技术

- **L1/L2 正则化**：在损失函数中添加权重的范数惩罚
- **Dropout**：训练时随机丢弃部分神经元，防止过拟合
- **Batch Normalization**：标准化每一层的输入，加速训练
- **早停（Early Stopping）**：验证集性能不再提升时停止训练

## 3.4 卷积神经网络（CNN）

CNN 专门用于处理网格状数据（如图像），核心操作包括：

- **卷积操作**：使用滤波器（卷积核）在输入上滑动，提取局部特征
- **池化**：下采样操作，降低特征维度（最大池化、平均池化）
- **全连接层**：将提取的特征映射到最终输出

### 3.4.1 经典 CNN 架构

- **LeNet-5**：最早用于手写数字识别
- **AlexNet**：2012 年 ImageNet 冠军，深度学习复兴的开端
- **VGGNet**：证明了网络深度的重要性
- **ResNet**：引入残差连接，解决了深层网络的退化问题
- **GoogLeNet/Inception**：引入 Inception 模块

## 3.5 循环神经网络（RNN）

RNN 专门处理序列数据（如文本、时间序列）：

- **基本 RNN**：在每个时间步共享权重
- **LSTM（长短期记忆）**：通过遗忘门、输入门、输出门解决长期依赖问题
- **GRU**：LSTM 的简化版本，参数更少

## 3.6 Transformer 架构

Transformer 完全基于注意力机制，2017 年由 Google 提出，彻底改变了 NLP 领域：

- **自注意力机制（Self-Attention）**：捕捉序列中每个位置与其他位置的关系
- **多头注意力**：从多个角度学习注意力权重
- **位置编码**：为序列中的每个位置添加位置信息
- **编码器-解码器结构**：编码器理解输入，解码器生成输出

### 3.6.1 基于 Transformer 的模型

- **BERT**：双向编码器，理解上下文
- **GPT 系列**：自回归解码器，擅长文本生成
- **T5**：编码器-解码器架构，统一了 NLP 任务
